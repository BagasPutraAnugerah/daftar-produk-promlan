Prasyarat:
- JDK 11 atau versi lebih baru
- Apache Maven
- IDE NetBeans

# Cara Run Projek
- Clone repository
git clone 
cd Promlan2
- Run lewat Terminal / CMD
mvn clean compile javafx:run
- Run lewat IDE (NetBeans / IntelliJ / VS Code)
Open folder Promlan2 sebagai project Maven.
Buka file src/main/java/kelas/MainApp.java
Klik Run atau Play.
